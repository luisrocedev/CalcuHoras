# CalcuHoras

Calculador de Horas de Trabajo

## Descripción

CalcuHoras es una aplicación sencilla en C++ que permite calcular las horas trabajadas durante una semana (5 días) y el dinero total ganado, introduciendo las horas diarias y el salario por hora. Es ideal como ejercicio introductorio para aprender los fundamentos de C++.

## Uso

1. Compila el programa con:
   ```sh
   g++ main.cpp -o calcu_horas
   ```
2. Ejecuta el programa:
   ```sh
   ./calcu_horas
   ```
3. Introduce las horas trabajadas cada día y el salario por hora cuando se solicite.
4. El programa mostrará el total de horas y el dinero ganado en la semana.

## Funcionalidades

- Solicita las horas trabajadas durante 5 días.
- Solicita el salario por hora.
- Calcula el total de horas y el total ganado.
- Muestra un resumen semanal por día y el total.

## Requisitos

- Compilador C++ (g++, clang++, etc.)
- Sistema operativo compatible: macOS, Linux, Windows

## Archivos principales

- `main.cpp`: Código fuente principal.
