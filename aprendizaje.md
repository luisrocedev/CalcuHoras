# Programación

## 1. Elementos fundamentales del código
- Uso de variables, arrays y bucles en C++.
- Tipos: double, int, vector.
- Ejemplo:
```cpp
vector<double> horas(5);
double salarioPorHora;
```

---

## 2. Estructuras de control
- Condicionales: if (no usado en este ejemplo, pero aplicable).
- Bucles: for para pedir las horas de cada día y mostrar resultados.
- Ejemplo:
```cpp
for (int i = 0; i < 5; ++i) {
    // ...
}
```
