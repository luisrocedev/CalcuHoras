# 🎤 Guion hablado para el Proyecto CalcuHoras

## Introducción

Hola, soy [tu nombre] y en este vídeo voy a presentar mi proyecto CalcuHoras, una pequeña aplicación de consola desarrollada en C++ para calcular las horas trabajadas y el dinero ganado en una semana. Este proyecto está pensado como una introducción práctica a la programación en C++.

---

## 1. Programación

CalcuHoras utiliza variables, arrays y bucles en C++ para pedir al usuario las horas trabajadas durante 5 días y el salario por hora. El cálculo del total de horas y del dinero ganado se realiza de forma sencilla y se muestra un resumen semanal.

La estructura es simple y todo el código está en un único archivo main.cpp, con comentarios para facilitar la comprensión.

---

## 2. Sistemas Informáticos

El desarrollo y las pruebas se han realizado en macOS, pero el programa es compatible con cualquier sistema que tenga un compilador de C++ (como g++). La aplicación se ejecuta en la consola y no requiere instalación adicional.

---

## 3. Entornos de Desarrollo

He utilizado Visual Studio Code y la terminal de macOS para editar, compilar y ejecutar el programa. El control de versiones se puede realizar con Git, aunque en este caso el proyecto es muy sencillo.

---

## 4. Bases de Datos

CalcuHoras no utiliza bases de datos, ya que todos los datos se introducen y procesan en memoria durante la ejecución.

---

## 5. Lenguajes de Marcas y Gestión de Información

No se utilizan lenguajes de marcas ni gestión avanzada de información, ya que el objetivo es practicar la lógica básica en C++.

---

## 6. Proyecto Intermodular

El objetivo de CalcuHoras es servir como ejercicio introductorio para aprender los fundamentos de C++: entrada y salida por consola, variables, arrays, bucles y operaciones aritméticas.
